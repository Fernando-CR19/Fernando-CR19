## 🚀 Projetos em destaque

### 🖨️ [Calculadora de Preços para Impressão 3D: API](https://github.com/Fernando-CR19/Calculadora-de-Custos-de-Impress-o-3D-Back)
> API REST construída com **Java** e **Spring Boot**

Substitui a planilha que eu usava para precificar as peças da minha loja de impressão 3D. Calcula o custo de cada peça (filamentos, desperdício, energia, depreciação da impressora, acabamento e consumíveis) e sugere o preço de venda, mostrando cada etapa do cálculo. Tem autenticação com JWT, dados separados por usuário, migrations versionadas e testes automatizados.

`Java` `Spring Boot` `Spring Security` `JWT` `PostgreSQL` `Flyway` `JUnit` `Mockito` `Docker`

> 🎨 [Front-end em **Angular**](https://github.com/Fernando-CR19/Calculadora-de-Custos-de-Impressora-3D-Front): _em desenvolvimento_
